# 🌊 Water Monitoring Dashboard

ระบบติดตามสถานการณ์น้ำแบบเรียลไทม์ จากเว็บไซต์กรมชลประทาน

## ✨ Features
- 📊 แดชบอร์ดแสดงสถานการณ์น้ำแบบเรียลไทม์
- 🤖 บอทดึงข้อมูลอัตโนมัติทุก 1 นาที
- 📈 แสดงกราฟแนวโน้มระดับน้ำ
- 🔔 ระบบแจ้งเตือนเมื่อน้ำเกินเกณฑ์
- 📱 รองรับ Line Notify
- 🗄️ เก็บข้อมูลใน SQLite
